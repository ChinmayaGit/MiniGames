Quick rules
Same suit → stack on TOP · Same rank → SIDE · Same face (J/J, Q/Q…) → FACE.
J +1 draw · Q skip · K +2 (stackable) · A extra turn · 0 reverse + block top · Wild picks suit.
Draw: no match → take 1. After Ks → take the whole stack (2, 4, 6…). Button shows Draw N. Caught → +3.
A slot is blocked only if that exact cell is already filled (screen overlap alone does not block).

How to play

Match a tip on the STACC. First empty hand wins.

  • ↑ TOP — same suit · → SIDE — same rank · ← FACE — same face (J/J…)
  • Drag a glowing hand cube onto a tip, or tap then pick a side
  • Topping a cube still leaves its side/face open
  • ↺ ↻ rotates the camera only (rules stay the same)
  • Pick a Deck theme on home/lobby (Space, Halloween…) — icons change for everyone
  • ◇ is UI colors only; deck icons come from the lobby theme
  • Same rank again? Keep dumping, then tap Done
  • Draw = 1 if no match; after Ks take the full stack (button shows Draw N)
  • J → next draws 1 then plays · Caught → +3
  • At 2 cards → tap UH OH! before going to 1
  • Watch Pile · N — if the deck runs out, you only get what’s left
